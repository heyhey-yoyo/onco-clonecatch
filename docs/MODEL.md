# CloneCatch v1.1 模型说明

## 1. 模型用途

CloneCatch 用于演示“肿瘤空间异质性 + 有限取样 + 检测阈值”如何改变研究者最终观察到的克隆组成。它不是患者特异性肿瘤数字孪生，也不输出临床结论。

## 2. 合成肿瘤

- 肿瘤被表示为二维离散网格。
- 克隆通过空间场分配到网格点，形成连续生态位。
- “稀有克隆总体占比”指该克隆在合成网格中的空间类别比例。
- 最后一个克隆永远被定义并标记为“稀有耐药克隆”。
- 固定随机种子时，肿瘤空间结构是确定的。

## 3. 虚拟芯针

每根芯针由中心坐标、角度、长度和宽度定义。正式 Monte Carlo 中，为避免芯针内部再引入一层随机抽样误差，使用固定 17×7 规则网格近似其克隆组成；当前手工放置芯针的读数使用合成肿瘤网格的精确几何包含判断。

芯针伸出肿瘤边界的部分不计入肿瘤克隆组成；本模型不单独模拟正常组织污染或肿瘤纯度。

## 4. 两种检测聚合方式

### 逐芯针独立检测

每根芯针分别计算克隆比例。只要任一芯针中某克隆比例达到检测阈值，即视为该克隆被捕获。

### 合并检测

先合并全部芯针中的合成克隆计数，再对合并后的总体克隆比例应用检测阈值。

这两种模式回答的是不同实验流程问题，因此界面和导出 Methods 中始终明确记录所选模式。

## 5. 指标

### 稀有克隆漏检率

在重复虚拟取样中，稀有耐药克隆没有达到所选检测规则的比例。

### 克隆景观恢复率

真实存在于合成肿瘤中的克隆类别中，被当前检测规则捕获的类别比例。

### 代表性

`1 - TVD`，其中 TVD 为样本合并克隆组成与全肿瘤克隆组成之间的总变差距离：

`TVD = 0.5 × Σ |sample_k - truth_k|`

代表性越接近 1，表示样本的总体克隆组成越接近完整合成肿瘤。

### Wilson 95% Monte Carlo 区间

对漏检次数/总重复次数这个二项比例使用 Wilson 区间。它只反映有限 Monte Carlo 次数造成的模拟误差，不是患者、生物学效应或临床性能的置信区间。

## 6. 策略

- 随机芯针：在肿瘤内部随机取中心位置和角度。
- 中心偏置：芯针中心集中于肿瘤中心区域。
- 中心 + 边缘：交替从中央和外周区域取样。
- 空间分散：从候选点中迭代选择与已有芯针距离较大的位置。

这些策略是教学/方法学演示的抽象，不对应任何特定癌种的临床取样指南。

## 7. 明确未建模内容

- VAF、测序深度、测序错误率
- 肿瘤纯度、正常组织混入
- 拷贝数、倍体、LOH
- 真实组织形态、坏死、基质和免疫细胞
- 单细胞谱系树或患者真实空间组学
- 治疗反应、预后、诊断性能
- 患者级最优活检方案
